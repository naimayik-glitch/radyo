# radyo

Mac için açık kaynak radyo, M3U ve çoklu YouTube oynatıcısı.

Dağıtım hazırlığı sürüyor. Kaynak ve doğrulanmış Mac kurulum paketi bu depoya eklenecek; henüz indirilebilir bir sürüm yayımlanmadı.

- Radyo istasyonu arama ve favoriler
- Kendi M3U URL veya dosyanızdan televizyon kitaplığı
- 1 / 2 / 4 YouTube ekranı
- Kendi Google hesabınızla salt okunur abonelik / oynatma listesi erişimi

Tanıtım ve gizlilik: https://naimayik-glitch.github.io/radyo/

Windows / Linux sürümü yoktur. Mac dağıtımı ve Google üretim yetkilendirmesi doğrulanmadan tamamlandı olarak sunulmaz.
